# Design System

**Status:** 🔒 LOCKED

Dokumen ini merupakan standar visual resmi yang wajib digunakan pada seluruh halaman Web Application.

Dokumen ini **bukan** Business Requirement.

Dokumen ini merupakan pedoman UI/UX agar seluruh aplikasi memiliki tampilan yang konsisten.

---

# 1. Design Philosophy

Design System menggunakan tema:

> **Retro Neo Brutalism Design**

Karakter utama:

- Modern
- Tegas
- Clean and Clear
- Friendly User
- Responsive
- Accessible

Seluruh halaman harus memiliki identitas visual yang sama.

---

# 2. Design Principles

Seluruh desain harus mengikuti prinsip berikut.

- Simplicity
- Consistency
- Readability
- Accessibility
- Mobile First
- Responsive
- User Focused

UI tidak boleh terlihat seperti:

- Bootstrap Default
- AdminLTE
